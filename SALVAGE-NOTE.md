# What this branch is

The verbatim v0.1.0 working copy of this package that was found untracked in the `ui` repo on
2026-08-18 — a second, divergent master that had never been committed anywhere.

`main` took the two shape files for vendors the estate still calls (Cloudflare, Resend) and shipped
them as v0.3.0 behind the `./shapes` subpath. The other three — `vercel.ts`, `supabase-mgmt.ts`,
`github.ts` — were deliberately dropped, because the estate exited those vendors.

This branch exists so "dropped" does not mean "destroyed". Nothing here is maintained, and nothing
here should be merged: the rest of this tree is v0.1.0 and is strictly behind `main`.
